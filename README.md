## Desarrollo local

La web está hecha con HTML, CSS y JavaScript. Para abrirla por HTTP, ejecutar desde la raíz del repositorio:

```sh
python -m http.server 8000 --bind 127.0.0.1
```

Después, abrir `http://127.0.0.1:8000`.
